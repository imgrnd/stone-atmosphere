# Вёрстка по плану

Следуй правилу `.cursor/rules/layout.mdc`. Если задача — главная или первый экран, сначала прочитай [home-hero.md](home-hero.md).

## Порядок

1. Прочитай текущий план и макеты, которые в нём указаны.
2. Собери пробелы, без которых блок нельзя сверстать, и задай их одним сообщением. К коду переходи после ответа.
3. Сверстай согласованный объём этой задачи — прямое чтение плана и макета, без соседних правок и без второго прохода «на всякий случай».
4. Открой страницу в браузере и проверь узкую и широкую ширину: порядок блоков, кадр, отступы, текст, кликабельные элементы.

Навык задаёт порядок работы. Вёрстку начинает запрос пользователя.
