# Первый экран главной

Макет: [home-hero.jpg](home-hero.jpg). Объём — шапка и первый экран. Секций ниже нет.

Следуй `.cursor/rules/layout.mdc`. Стек: семантический HTML, `styles.css`, JS без сборки.

## Шапка

По кадру: знак, «Атмосфера камня», строка «Изделия для вашего интерьера», пункты «Материалы», «Изделия», «Производство», «Проекты», кнопка «Обсудить проект».

## Hero

- Слева над заголовком: «Кварцевый агломерат · Акриловый камень».
- Заголовок не меняется: «Камень, который становится атмосферой».
- Справа описание текущего слайда и кнопка «Рассчитать мой проект».
- Под фото круг со стрелкой вниз. Секции под ним нет: кнопка видимая и никуда не ведёт.
- Фото на всю ширину содержимого.

На мобильном те же блоки друг под другом, кадр 4:5. На ПК композиция кадра и фото 16:9.

Заголовок — системный шрифт с засечками, остальной текст — системный без засечек. Свой шрифт не подключать. Знак логотипа не рисовать.

## Слайды

Кадр, описание и подпись меняются вместе.

1. 01 Кухня — `imgs/01 Кухня — Мобильный 4_5.png`, `imgs/01 Кухня — ПК 16_9.png`. Описание: «Изготавливаем столешницы и интерьерные изделия по индивидуальным размерам. От выбора фактуры до точной посадки в вашем пространстве.»
2. 02 Ванная — `imgs/02 Ванная — Мобильный 4_5.png`, `imgs/02 Ванная — ПК 16_9.png`.
3. 03 Интерьер — `imgs/03 Интерьер — Мобильный 4_5.png`, `imgs/03 Интерьер — ПК 16_9.png`.
4. 04 Коммерческие объекты — `imgs/04 Коммерческие объекты — Мобильный 4_5.png`, `imgs/04 Коммерческие объекты — ПК 16_9.png`.

Подписи этих четырёх слайдов стоят на фото, активная выделена, как на кадре.

Слайдер идёт по кругу сам. Две стрелки стоят в правом блоке, в одной секции с кнопкой «Рассчитать мой проект». Стрелка или клик по подписи сразу меняет кадр, описание и активную подпись и начинает интервал заново.
